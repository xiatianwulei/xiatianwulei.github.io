# KMP 分层开发指南 —— 勋章详情页（MedalDetail）实现记录

> 模式：**KMP 提供网络请求、数据模型、业务逻辑（ViewModel）；iOS 原生负责 UI 展示。**
> 本文记录勋章详情页在 ruyi-app（KMP）各层、以及 wandafilm-mine（iOS）各文件的**具体改动与新增内容**。
> 后续实现其他页面，照着本文件的「改了什么 / 加了什么」逐层抄即可。

---

## 一、ruyi-app（KMP）各层改动

### 1. domain 领域层

| `mine/medal/repository/MedalDetailRepository.kt` | 修改 | 接口新增 `getMedalDetail(medalId): Result<MedalDetail>` 与 `receiveMedalEquity(medalId, equityId): Result<UserMedalInfo>` |

### 2. data 数据层
路径前缀：`app-common/data/src/commonMain/kotlin/com/app/common/data/`

| 文件 | 操作 | 内容 |
|------|------|------|
| `mine/medal/dto/MedalDetailDTO.kt` | 新建 | 网络 DTO `MedalDetailDTO`（字段对齐领域模型）+ 外层包裹 `MedalDetailWrapperDTO(medal: MedalDetailDTO?)` |
| `mine/medal/mapper/MedalDetailMapper.kt` | 新建 | `MedalDetailDTO.toDomain()` 与 `EquityItemDTO.toDomain()` 映射 |

| `mine/medal/repository/MedalRepositoryImpl.kt` | 修改 | 实现 `MedalDetailRepository`，取 `wrapper.medal` 再 `toDomain()` |
| `DataModule.kt` | 修改 | Koin 注册（`single`/`factory`，用显式泛型）：`MedalDetailRepository`、`GetMedalDetailUseCase`、`ReceiveMedalEquityUseCase` |

### 3. app-main 层（ViewModel + Koin）
路径前缀：`app-main/mine/src/commonMain/kotlin/com/app/main/mine/`

| 文件 | 操作 | 内容 |
|------|------|------|
| `medal/MedalDetailViewModel.kt` | 新建 | `MedalDetailEvent`/`MedalDetailState`/`MedalDetailAction` 三个**顶层声明**；`abstract class MedalDetailViewModel : BaseViewModel<...>()`；`MedalDetailViewModelImpl` 实现 `onTriggerEvent`（Enter→加载详情，Receive→领取并成功后刷新） |
| `MineModule.kt` | 修改 | Koin 注册 ViewModel（**接口 + 实现类各一份**）：`factory<MedalDetailViewModel> { MedalDetailViewModelImpl(...) }` 与 `factory { MedalDetailViewModelImpl(...) }` |

`MedalDetailViewModel.kt` 结构：
```kotlin
sealed class MedalDetailEvent : ViewEvent {
    data class Enter(val medalId: Int) : MedalDetailEvent()
    data class Receive(val medalId: Int, val equityId: Int) : MedalDetailEvent()
}
sealed class MedalDetailAction : ViewSingleAction {
    data class ShowReceiveResult(val message: String) : MedalDetailAction()
}
data class MedalDetailState(
    val isLoading: Boolean = false,
    val detail: MedalDetail? = null,
    val error: UIComponent? = null
) : ViewState

abstract class MedalDetailViewModel :
    BaseViewModel<MedalDetailEvent, MedalDetailState, MedalDetailAction>() { }

class MedalDetailViewModelImpl(
    private val getMedalDetailUseCase: GetMedalDetailUseCase,
    private val receiveMedalEquityUseCase: ReceiveMedalEquityUseCase
) : MedalDetailViewModel() {
    override fun initialState() = MedalDetailState()
    override fun onTriggerEvent(event: MedalDetailEvent) {
        when (event) {
            is MedalDetailEvent.Enter -> loadMedalDetail(event.medalId)
            is MedalDetailEvent.Receive -> receiveEquity(event.medalId, event.equityId)
        }
    }
    // loadMedalDetail / receiveEquity 内部用 executeUseCase + setAction / setError
}
```

### 4. shared 层（iOS 暴露工厂）
路径：`shared/src/iosMain/kotlin/com/kmp/ruyi/app/viewmodel/factory/MineModuleWrapperFactory.kt`

| 文件 | 操作 | 内容 |
|------|------|------|
| `MineModuleWrapperFactory.kt` | 修改 | 新增 `createSkieMedalDetailVmWrapper()`；import 顶层 `MedalDetailEvent/State/Action` 与 `MedalDetailViewModel`/`MedalDetailViewModelImpl` |

```kotlin
import com.app.main.mine.medal.MedalDetailAction
import com.app.main.mine.medal.MedalDetailEvent
import com.app.main.mine.medal.MedalDetailState
import com.app.main.mine.medal.MedalDetailViewModel
import com.app.main.mine.medal.MedalDetailViewModelImpl

fun createSkieMedalDetailVmWrapper(): SkieViewModelWrapper<MedalDetailEvent, MedalDetailState, MedalDetailAction> =
    skieViewModelWrapperOf<MedalDetailViewModelImpl, MedalDetailEvent, MedalDetailState, MedalDetailAction>()
```

> `skieViewModelWrapperOf` 第一个泛型是 Koin 中 `get()` 取的类型（实现类），后三个是 Event/State/Action。工厂文件包名不同，必须 import 顶层类型。

**ruyi-app 编译后，需重新导出 `RuyiShared.framework` 供 iOS 使用。**

`BaseKMPSKIEViewController` 新增初始化器：

```swift
    self.wrapper = wrapper
    super.init(nibName: nibName, bundle: bundle)

```

`MedalDetailKMPViewController` 核心结构：
```swift
import UIKit
import RuyiShared
import WandaFilmCore

class MedalDetailKMPViewController:
    BaseKMPSKIEViewController<MedalDetailEvent, MedalDetailState, MedalDetailAction> {

    @IBOutlet weak var tableView: UITableView!
    @IBOutlet weak var obtainBtn: UIButton!
    @objc var medalId: Int = 0
    private var entity: WandaFilm_Mine.MedalDetail?
    private var sectionItems: [WandaFilm_Mine.EquityItem] = []

    init(medalId: Int) {
        self.medalId = medalId
        let wrapper = createSkieMedalDetailVmWrapper()
        super.init(wrapper: wrapper, nibName: "MedalDetailKMPViewController", bundle: Bundle.mine)
    }

    override func viewWillAppear(_ animated: Bool) {
        super.viewWillAppear(animated)
        wrapper.setEvent(event: MedalDetailEvent.Enter(medalId: Int32(medalId)))
    }

    override func updateUI(state: MedalDetailState) {
        guard let detail = state.detail else { return }
        let native = mapToNative(detail)   // detail: RuyiShared.MedalDetail
        self.entity = native                // native: WandaFilm_Mine.MedalDetail
        sectionItems = native.equity ?? []
        tableView.reloadData()
    }

    override func handleAction(action: MedalDetailAction) {
        switch onEnum(of: action) {
        case .showReceiveResult(let result): Toast.show(result.message)
        default: break
        }
    }

    override func handleError(uiComponent: UIComponent_) {
        super.handleError(uiComponent: uiComponent)
        // onEnum(of:) -> .toast / .failure / .network
    }

    private func mapToNative(_ detail: RuyiShared.MedalDetail) -> WandaFilm_Mine.MedalDetail { /* 字段逐一转换 */ }
}
```

cell 领取回调注入（KMP VC 配置 cell 时）：
```swift
cell.onReceiveAction = { [weak self] equityId, medalId in
    self?.wrapper.setEvent(event: MedalDetailEvent.Receive(medalId: Int32(medalId), equityId: Int32(equityId)))
}
```

> 同名类型冲突：`RuyiShared.MedalDetail` 与原生 `WandaFilm_Mine.MedalDetail` 同名，因 `import RuyiShared` 裸写会优先解析为 KMP 的，必须显式加模块前缀（`RuyiShared.` / `WandaFilm_Mine.`）。

## 四、实现其他页面的标准步骤（照抄）

### KMP 侧（ruyi-app）
1. **domain**：建领域模型；建 `XxxRepository` 接口；建 `GetXxxUseCase` / `DoXxxUseCase`（含 `Params`）。
2. **data**：建 `XxxDTO.kt`（注意后端 JSON 是否有外层包裹，有则加 `XxxWrapperDTO`）；建 `XxxMapper.kt`；`XxxApi.kt` 加接口与地址；`XxxRepositoryImpl.kt` 实现接口；`DataModule.kt` 用显式泛型注册。
3. **app-main**：建 `XxxViewModel.kt`，`Event/State/Action` 写成**顶层声明**；`MineModule.kt` 注册接口 + 实现类各一份。
4. **shared**：`MineModuleWrapperFactory.kt` 加 `createSkieXxxVmWrapper()`（import 顶层类型），用 `skieViewModelWrapperOf<XxxViewModelImpl, XxxEvent, XxxState, XxxAction>()`。
5. 编译 ruyi-app，**重新导出 RuyiShared.framework**。

### iOS 侧（wandafilm-mine）
1. 新建 `XxxKMPViewController`，继承 `BaseKMPSKIEViewController<XxxEvent, XxxState, XxxAction>`。
2. `init()` 里 `createSkieXxxVmWrapper()` 拿 wrapper，用 `super.init(wrapper:nibName:bundle:)` 加载 xib。
3. 实现 `updateUI(state:)` / `handleAction(action:)` / `handleError(uiComponent:)`。
4. 同名的 KMP 模型做 KMP→原生转换，显式加 `RuyiShared.` / `WandaFilm_Mine.` 前缀。
5. 交互通过 `wrapper.setEvent(event: XxxEvent.xxx(...))` 回传 KMP（`Int` 用 `Int32(...)`）。
6. 在某个列表入口 `RouterService.open(XxxKMPViewController(...))` 验证，通过后替换原生 VC。
